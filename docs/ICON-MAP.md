# BloodNorms — Cupertino Icon Mapping

Every icon in the product uses the official CupertinoIcons font (`cupertino_icons` package) per `05-UI-UX-DESIGN-SYSTEM.md §2`.

| Intent | Cupertino Glyph Name | Used For |
|---|---|---|
| Brand / Blood | `drop_fill`, `drop` | App logo, Hero Need Blood button, blood component tiles |
| Donor / Health | `heart_fill`, `heart` | Donor portal CTA, Donor onboarding |
| Location | `location_solid`, `location_fill` | Map markers, GPS button, distance chips |
| Call | `phone_fill`, `phone` | Direct call to donor / blood bank |
| Chat | `chat_bubble_fill` | WhatsApp entry button |
| Voice | `mic_fill` | Phone assistant info & inbound tab |
| Blood Bank | `building_2_fill` | Blood bank cards & navigation |
| Search | `search` | Search donors CTA, Search fields |
| Clock / Urgency | `clock`, `clock_fill`, `bolt_fill` | Freshness chips, ETA display, Urgency selector |
| Calendar | `calendar` | Camps tab, 24h urgency |
| Verified / OK | `checkmark_circle_fill`, `checkmark` | Accepted donor badge, Success sheets |
| Warning / Gate | `exclamationmark_triangle_fill` | Gate warnings, Far search notice |
| Stop / Cancel | `stop_fill`, `xmark_circle_fill` | Kill switch, Stop search CTA |
| Chevrons | `chevron_right`, `chevron_back`, `chevron_down` | Row navigation & sheets |
| Steppers | `plus_circle_fill`, `minus_circle_fill` | Units counter & stock steppers |
| Admin / Safety | `shield_fill`, `lock_fill` | Admin Console, Security disclaimers |
| Ticket | `ticket_fill` | Wallet-style donation pass |
| Keypad Delete | `delete_left_fill` | 6-digit passcode keypad |
| Badges | `rosette`, `star_fill`, `gift_fill` | Proven donor badges, Goodies kit |
